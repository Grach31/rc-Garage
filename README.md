# RC Garage 2.0 · Minimal Collection

Опубликованная персональная коллекция. Галерея и страницы 10 моделей; поиск,
фильтры и компоновка по референсу владельца: постоянная боковая панель с
миниатюрами моделей, широкий первый экран, четыре параметра, вкладки и сетка
компонентов 3 × 2. На мобильных устройствах панель раскрывается из верхнего меню,
карточки компонентов идут в две колонки. Вкладки поддерживают клавиатуру,
прямые ссылки и возврат браузера. Компоненты и фотографии открываются в диалоге.
Сайт: https://grach31.github.io/rc-Garage/ . Публикация GitHub Pages из корня main.
Изменения готовятся в отдельных ветках, публикация — после разрешения владельца.

## Запуск

Нужен Python 3: `python3 -m http.server 4173`, затем открыть
http://localhost:4173. Или `npm start` (Node используется только для команды).
Сборка и установка зависимостей не требуются. Проверка JS: `npm run check`.

## Архитектура

- `index.html`, `styles.css`, `app.js` — статическое приложение без фреймворка.
- `data/collection.json` — каталог и единственный источник сведений.
- `assets/` — фотографии владельца; инструкция в `assets/README.md`.
- `docs/` — снимки главной страницы и страницы модели на компьютере и iPhone.

Новый репозиторий содержал только README. Прежний проект и его подтверждённые
данные не предоставлены. Каталог использует сведения владельца и проверенные источники для CrossRC EMO X5;
неизвестные поля равны null и отображаются как «Не указано».
Производители самодельных моделей не выводятся из названий настоящих грузовиков.
6S в названии GT не используется как подтверждение параметров аккумулятора.
1:10 указан только для прицепа. CrossRC EMO X5 — 1:8, Brushless RTR; владелец
подтвердил штатную комплектацию и разрешил добавление найденных каталожных фото.
Рулевая серва DS-R003C: 25 кг·см при 7,4 В. OEM мотор и ESC — единая система
Hobbywing FUSION 8IGHT. Масса и модель установленного аккумулятора неизвестны.
Фотографии CrossRC являются каталожными; происхождение подписано в интерфейсе.
Остальные модели используют явные заглушки «Фото не добавлено».
Источники: `docs/crossrc-emo-x5-sources.json`; в каталоге — поле `sources`.

## Как менять сведения и фото

Редактируйте соответствующую запись JSON. `image` — относительный путь к обложке,
`gallery` — массив путей или объектов `{src, caption, credit, sourceUrl}`.
`thumbnail` — маленькая обложка; `imageCredit` и `imageSourceUrl` — авторство
и источник фото. `configurationNote` — примечание о комплектации.
`stockConfirmed` отмечает подтверждение штатной комплектации владельцем. Компоненты: `manufacturer`, `model`, `name` (читаемое название при неизвестной
точной модели), `image`, `imageCredit`, `imageSourceUrl`, `sourceUrl`,
`specifications` (строка), `notes`. Поле компонента `category`: `motor`, `esc`,
`servo`, `suspension` или `wheels` связывает его с карточкой обзора; остальные
компоненты выводятся отдельно. Характеристики в `specifications` модели:
`dimensions`, `weight`, `motor`, `esc`, `servo`, `battery`, `suspension`, `wheels`,
`transmission`, `type`, `drive`. `settings` модели — текст настроек; `upgrades` и
`service` — массивы строк. `type` и `drive` не выводятся из названия модели. При отсутствии сведений оставляйте null или поле незаполненным.
Программную логику менять не нужно. Предусмотрены ленивая загрузка, фиксированные
пропорции и обработка недоступных фото; подготовка изображений — вручную. Файлы CrossRC преобразованы в WebP
с длинной стороной до 1800 px, миниатюра — 600 px; композиция и логотипы сохранены.

## Границы этапа

Следующие этапы: редактор сведений и компонентов, загрузка и сжатие
фотографий, локальное сохранение (IndexedDB), экспорт/импорт резервной копии с
валидацией, редактируемые тюнинг и журнал обслуживания. Сейчас этих функций нет;
разделы обслуживания показывают пустое состояние. Внешних API, регистрации,
Three.js и сетевых шрифтов нет. Сервер нужен только для раздачи статики.

## GitHub Pages

Архитектура поддерживает Pages: относительные пути и маршруты через hash работают
в подпапке репозитория. GitHub Pages публикует корень main автоматически после слияния.
Для private-репозитория Pages требует подходящего платного тарифа GitHub; на Free
понадобится public-репозиторий. Публикация включена владельцем.

## Проверка

Chromium: 10 записей, фильтры, поиск и пустой результат, переходы, возврат,
перезагрузка страницы модели, пять вкладок, управление вкладками с клавиатуры,
диалог компонента, мобильное меню, неизвестный маршрут и отсутствие фотографии.
Все 10 моделей проверены на переполнение при ширинах 320, 375, 390, 768,
1024 и 1440 px.
Снимки в docs. Это эмуляция размеров экрана, а не проверка на физическом iPhone
или Safari. Финальная оценка композиции с реальными фотографиями — после их
предоставления владельцем.
